PROJECT REPORT
AMAZON CLONE WEBSITE USING HTML AND CSS

Abstract:
The Amazon Clone Website is a frontend web development project created using HTML and CSS. The project aims to design a shopping homepage inspired by Amazon. It includes a navigation bar, hero section, shopping categories, featured products, and footer. The website uses CSS Flexbox, Grid, hover effects, and media queries to create an attractive and responsive layout.
Introduction:
This project is developed to understand the fundamentals of web development. The website recreates the basic design of an online shopping platform using HTML for structure and CSS for styling. It is a static website created for educational purposes.
Objectives:
•	To create an Amazon-inspired homepage.
•	To understand HTML and CSS.
•	To design a navigation bar and hero section.
•	To display shopping categories and featured products.
•	To implement responsive web design.
Technologies Used:
•	HTML5: Used to create the structure of the webpage.
•	CSS3: Used for styling, layouts, colors, and responsive design.
•	Visual Studio Code: Used as the code editor.
•	Google Chrome: Used for testing the website.
Project Structure:
•	Amazon-Clone/
│
├── index.html
└── style.css
•	The index.html file contains the webpage structure, while the style.css file controls the design and layout.
Features:
•	Amazon-inspired navigation bar with search bar and cart.
•	Hero banner with promotional text and button.
•	Shopping category cards with images.
•	Featured products with names and prices.
•	Footer containing useful links.
•	Responsive layout for desktop, tablet, and mobile devices.
•	Hover effects for cards, links, and buttons.
Responsive Design:
CSS media queries are used to adjust the website according to different screen sizes. The product grid changes from four columns on desktop to two columns on tablets and one column on mobile devices.
Conclusion:
The Amazon Clone Website was successfully developed using HTML and CSS. This project helped in understanding webpage structure, styling, Flexbox, Grid, and responsive design. The project fulfills the requirements of creating a homepage, navigation bar, hero section, footer, and responsive layout using only HTML and CSS.
